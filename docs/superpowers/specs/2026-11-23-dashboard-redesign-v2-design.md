# Dashboard v2 — спека (Qt Quick/QML пересборка UI)

Решение: вью-слой — QML (ApplicationWindow), бэкенд — тот же Python без регрессий.
Одна скролл-страница, единая строка-анатомия, нижняя шторка лога, статусбар.
Основание: research/2026-11-23-dashboard-redesign (конкуренты, dark-UI токены,
лимиты QSS — Qt 6.12 официально позиционирует QSS для прототипирования).

## Архитектура

```
dashboard.py   — entry: QApplication, QQmlApplicationEngine, трей, запуск
backend.py     — ВЕСЬ код без UI: конфиги, пробы, watchdog, реестр, API :4850,
                 env-helpers, proc-утилиты. Функции переезжают с минимальными
                 правками; чистый Python + psutil + winreg + http.server.
bridge.py      — DashboardBridge(QObject): pyqtSlot для всех действий,
                 модели строк (QAbstractListModel) на каждую секцию,
                 probe worker → payload → update-in-place моделей.
ui/Main.qml    — шелл: шапка, ListView-секции, лог-шторка, статусбар, диалоги.
ui/components  — Row.qml (одна на все 4 секции!), Pill.qml, IconBtn.qml,
                 Sheet.qml, editors.
```

Backend НЕ меняет семантику: probe→signal 4с, watchdog ≥30с cooldown,
monitor_only без контролов, Origin-check POST, StartupApproved-байты,
env-токен механика, конфиги и ключи — как есть. Дешёвые багфиксы из аудита
в том же проходе: LISTEN-only в kill_process_by_port, атомарная запись
конфигов (tmp+rename), ProjectDialog-аналог сохраняет неизвестные ключи,
process-scan из GUI-тика уходит в probe worker.

## Информационная архитектура (из Q1)

Одна страница, секции сверху вниз: ИНФРА · ЛОКАЛЬНЫЕ → ИНФРА · УДАЛЬНЫЕ
(если есть remote-specs) → ПРОЕКТЫ → АВТОЗАПУСК (свои; сторонние под
expander'ом «сторонние · N»). Сайдбар отклонён — ~20 строк, нужен один
взгляд, не навигация.

Шапка секции: `CAPS muted` слева, групповые действия справа ghost-кнопками
(▶ все / ■ все / + добавить / сканировать / убить порт).

## Строка — единая анатомия (фикс жалобы #1)

GridLayout, жёсткие колонки, одинаковые для всех секций:

```
[пилюля 84px][имя semibold 13 + причина/sub 11 muted][чип-ссылка][метрики mono 11 right][слот1][слот2][меню]
 |<-- flex -->|                                        |<-- flex min 160 -->|   28  28  28
```

- Высота строки 44px, hover surface→elevated 120ms, у упавшей — красная
  кромка 2px СЛЕВА заложена в колонку (padding, не border → без сдвига).
- Пустой слот действия = прозрачный плейсхолдер 28px → колонки ровные
  на monitor_only/remote/проектах/автозапуске одинаково.
- Действия: [▶/■] [↻] [⋯]; автозапуск: [вкл-тумблер] [✎] [⋯ с удалить].
- Причина сбоя — красной строкой под именем + действие-фикс («убить pid»).
- Пилюля: фон tint ~14% альфа от цвета состояния + слово полным цветом,
  радиус 10, одна ширина 84px везде. Словарь: работает / остановлен /
  упал / выкл / проверка (точка пульсирует только в переходном состоянии).
- monitor_only/remote: без ▶/■/↻, ⋯ остаётся (лог/url/папка/редакт/удалить).

## Токены (GitHub Primer dark семейство, из Q2 — проверено контрастом)

```
bg        #0d1117   surface   #161b22   elevated #21262d   hover #292e36
border    #30363d   borderDim #21262d
text      #f0f6fc   muted     #9198a1   faint    #6e7681
accent    #4493f8   ok        #3fb950   warn     #d29922    bad #f85149
pill bg   = цвет состояния @ 14% alpha
```

Типографика: имя Segoe UI 13 semibold; sub/причина 11 muted;
порты/метрики/pid Cascadia Mono 11 (табличные цифры нативно);
CAPS-секции 10.5 letterspaced muted. Ничего < 10.5px.

Motion: hover 120ms, лог-шторка 220ms, появление диалога 120ms fade+scale,
пульс «проверка» только в переходном состоянии. НИЧЕГО не анимируется
на тиках пробы.

## Нижний край

- Статусбар 28px: `● N ок` слева; `⚠ k` (если k>0) — кликабельный popover
  со списком проблемных строк, клик → прокрутка к строке.
- Лог-шторка: заголовок «ЛОГ» + фильтр-теги + «ошибки» тогл + очистить;
  раскрытие 220ms; внутри ListView, cap 2000 строк, autoscroll lock.
- Ctrl+L — toggle лога.

## Диалоги (QML, в окне — как sheet)

Редактор сервиса (включая type: local/http/tcp/docker — впервые remote
редактируем из UI), редактор проекта, редактор автозапуска, токен-диалог
(env_key/env_file), убить-порт, скан-результаты, подтверждения stop/kill
с именами процессов. Формы: валидные края, фокус-обводка accent.
