- Detection: "Reads the process's working directory to name the project, and shows the git branch it is on." Infra by name: "PostgreSQL, Redis, MongoDB, MySQL, Ollama and Docker containers."
- Health: "Every port is ok, error or timeout, with uptime, CPU and memory next to it." Page title/favicon probe: "A quick probe shows what each port actually serves."
- "Who started it — VS Code, iTerm, tmux or Claude Code. pier can jump straight back to the terminal that did."
- Idle/stale: "Servers idle for days get an idle badge, and one click or pier prune cleans them up."
- Tunnels: "`pier expose` opens a Cloudflare quick tunnel and gives you an HTTPS address to share."
- Dependencies/stacks: "`pier up` — Start a whole pier.yml stack, in dependency order."
