## Detailed Description[](https://doc.qt.io/qt-6/qvariantanimation.html#details "Direct link to this headline")

This class is part of [The Animation Framework](https://doc.qt.io/qt-6/animation-overview.html). It serves as a base class for property and item animations, with functions for shared functionality.

The class performs interpolation over [QVariant](https://doc.qt.io/qt-6/qvariant.html)s, but leaves using the interpolated values to its subclasses. Currently, Qt provides [QPropertyAnimation](https://doc.qt.io/qt-6/qpropertyanimation.html), which animates Qt [properties](https://doc.qt.io/qt-6/properties.html). See the [QPropertyAnimation](https://doc.qt.io/qt-6/qpropertyanimation.html) class description if you wish to animate such properties.

You can then set start and end values for the property by calling [setStartValue](https://doc.qt.io/qt-6/qvariantanimation.html#startValue-prop)() and [setEndValue](https://doc.qt.io/qt-6/qvariantanimation.html#endValue-prop)(), and finally call [start](https://doc.qt.io/qt-6/qabstractanimation.html#start)() to start the animation. QVariantAnimation will interpolate the property of the target object and emit [valueChanged](https://doc.qt.io/qt-6/qvariantanimation.html#valueChanged)(). To react to a change in the current value you have to reimplement the [updateCurrentValue](https://doc.qt.io/qt-6/qvariantanimation.html#updateCurrentValue)() virtual function or connect to said signal.

It is also possible to set values at specified steps situated between the start and end value. The interpolation will then touch these points at the specified steps. Note that the start and end values are defined as the key values at 0.0 and 1.0.

There are two ways to affect how QVariantAnimation interpolates the values. You can set an easing curve by calling [setEasingCurve](https://doc.qt.io/qt-6/qvariantanimation.html#easingCurve-prop)(), and configure the duration by calling [setDuration](https://doc.qt.io/qt-6/qvariantanimation.html#duration-prop)(). You can change how the [QVariant](https://doc.qt.io/qt-6/qvariant.html)s are interpolated by creating a subclass of QVariantAnimation, and reimplementing the virtual [interpolated](https://doc.qt.io/qt-6/qvariantanimation.html#interpolated)() function.

Subclassing QVariantAnimation can be an alternative if you have [QVariant](https://doc.qt.io/qt-6/qvariant.html)s that you do not wish to declare as Qt properties. Note, however, that you in most cases will be better off declaring your [QVariant](https://doc.qt.io/qt-6/qvariant.html) as a property.

Not all [QVariant](https://doc.qt.io/qt-6/qvariant.html) types are supported. Below is a list of currently supported [QVariant](https://doc.qt.io/qt-6/qvariant.html) types:

*   [Int](https://doc.qt.io/qt-6/qmetatype.html#Type-enum)
*   [UInt](https://doc.qt.io/qt-6/qmetatype.html#Type-enum)
*   [Double](https://doc.qt.io/qt-6/qmetatype.html#Type-enum)
*   [Float](https://doc.qt.io/qt-6/qmetatype.html#Type-enum)
*   [QLine](https://doc.qt.io/qt-6/qmetatype.html#Type-enum)
*   [QLineF](https://doc.qt.io/qt-6/qmetatype.html#Type-enum)
*   [QPoint](https://doc.qt.io/qt-6/qmetatype.html#Type-enum)
*   [QPointF](https://doc.qt.io/qt-6/qmetatype.html#Type-enum)
*   [QSize](https://doc.qt.io/qt-6/qmetatype.html#Type-enum)
*   [QSizeF](https://doc.qt.io/qt-6/qmetatype.html#Type-enum)
*   [QRect](https://doc.qt.io/qt-6/qmetatype.html#Type-enum)
*   [QRectF](https://doc.qt.io/qt-6/qmetatype.html#Type-enum)
*   [QColor](https://doc.qt.io/qt-6/qmetatype.html#Type-enum)

If you need to interpolate other variant types, including custom types, you have to implement interpolation for these yourself. To do this, you can register an interpolator function for a given type. This function takes 3 parameters: the start value, the end value, and the current progress.

Example:

Another option is to reimplement [interpolated](https://doc.qt.io/qt-6/qvariantanimation.html#interpolated)(), which returns interpolation values for the value being interpolated.

**See also**[QPropertyAnimation](https://doc.qt.io/qt-6/qpropertyanimation.html), [QAbstractAnimation](https://doc.qt.io/qt-6/qabstractanimation.html), and [The Animation Framework](https://doc.qt.io/qt-6/animation-overview.html).

## Property Documentation

### `[read-only]`currentValue : [QVariant](https://doc.qt.io/qt-6/qvariant.html)[](https://code.qt.io/cgit/qt/qtbase.git/tree/src/corelib/animation/qvariantanimation.h?h=6.12#n24 "View declaration of this property")[](https://doc.qt.io/qt-6/qvariantanimation.html#currentValue-prop "Direct link to this headline")

This property holds the current value of the animation.

This property describes the current value; an interpolated value between the [start value](https://doc.qt.io/qt-6/qvariantanimation.html#startValue-prop) and the [end value](https://doc.qt.io/qt-6/qvariantanimation.html#endValue-prop), using the current time for progress. The value itself is obtained from [interpolated](https://doc.qt.io/qt-6/qvariantanimation.html#interpolated)(), which is called repeatedly as the animation is running.

[QVariantAnimation](https://doc.qt.io/qt-6/qvariantanimation.html) calls the virtual [updateCurrentValue](https://doc.qt.io/qt-6/qvariantanimation.html#updateCurrentValue)() function when the current value changes. This is particularly useful for subclasses that need to track updates. For example, [QPropertyAnimation](https://doc.qt.io/qt-6/qpropertyanimation.html) uses this function to animate Qt [properties](https://doc.qt.io/qt-6/properties.html).

### `[bindable]`easingCurve : [QEasingCurve](https://doc.qt.io/qt-6/qeasingcurve.html)[](https://code.qt.io/cgit/qt/qtbase.git/tree/src/corelib/animation/qvariantanimation.h?h=6.12#n26 "View declaration of this property")[](https://doc.qt.io/qt-6/qvariantanimation.html#easingCurve-prop "Direct link to this headline")

**Note:**This property supports [QProperty](https://doc.qt.io/qt-6/qproperty.html) bindings.

This property holds the easing curve of the animation

This property defines the easing curve of the animation. By default, a linear easing curve is used, resulting in linear interpolation. Other curves are provided, for instance, [QEasingCurve::InCirc](https://doc.qt.io/qt-6/qeasingcurve.html#Type-enum), which provides a circular entry curve. Another example is [QEasingCurve::InOutElastic](https://doc.qt.io/qt-6/qeasingcurve.html#Type-enum), which provides an elastic effect on the values of the interpolated variant.

[QVariantAnimation](https://doc.qt.io/qt-6/qvariantanimation.html) will use the [QEasingCurve::valueForProgress](https://doc.qt.io/qt-6/qeasingcurve.html#valueForProgress)() to transform the "normalized progress" ([currentTime](https://doc.qt.io/qt-6/qabstractanimation.html#currentTime-prop)() / [totalDuration](https://doc.qt.io/qt-6/qabstractanimation.html#totalDuration)()) of the animation into the effective progress actually used by the animation. It is this effective progress that will be the progress when [interpolated](https://doc.qt.io/qt-6/qvariantanimation.html#interpolated)() is called. Also, the steps in the [keyValues](https://doc.qt.io/qt-6/qvariantanimation.html#keyValues) are referring to this effective progress.

The easing curve is used with the interpolator, the [interpolated](https://doc.qt.io/qt-6/qvariantanimation.html#interpolated)() virtual function, and the animation's duration to control how the current value changes as the animation progresses.

**Access functions:**

QEasingCurve**easingCurve**() const
void**setEasingCurve**(const QEasingCurve &_easing_)

### `[virtual protected]`[QVariant](https://doc.qt.io/qt-6/qvariant.html) QVariantAnimation::interpolated(const [QVariant](https://doc.qt.io/qt-6/qvariant.html)&_from_, const [QVariant](https://doc.qt.io/qt-6/qvariant.html)&_to_, [qreal](https://doc.qt.io/qt-6/qttypes.html#qreal-typedef)_progress_) const[](https://code.qt.io/cgit/qt/qtbase.git/tree/src/corelib/animation/qvariantanimation.h?h=6.12#n71 "View declaration of this function")[](https://doc.qt.io/qt-6/qvariantanimation.html#interpolated "Direct link to this headline")

This virtual function returns the linear interpolation between variants _from_ and _to_, at _progress_, usually a value between 0 and 1. You can reimplement this function in a subclass of [QVariantAnimation](https://doc.qt.io/qt-6/qvariantanimation.html) to provide your own interpolation algorithm.

Note that in order for the interpolation to work with a [QEasingCurve](https://doc.qt.io/qt-6/qeasingcurve.html) that return a value smaller than 0 or larger than 1 (such as [QEasingCurve::InBack](https://doc.qt.io/qt-6/qeasingcurve.html#Type-enum)) you should make sure that it can extrapolate. If the semantic of the datatype does not allow extrapolation this function should handle that gracefully.

You should call the [QVariantAnimation](https://doc.qt.io/qt-6/qvariantanimation.html) implementation of this function if you want your class to handle the types already supported by Qt (see class [QVariantAnimation](https://doc.qt.io/qt-6/qvariantanimation.html) description for a list of supported types).

**See also**[QEasingCurve](https://doc.qt.io/qt-6/qeasingcurve.html).

### template <typename T>void qRegisterAnimationInterpolator([QVariant](https://doc.qt.io/qt-6/qvariant.html) (*_func_)(const T&, const T&, [qreal](https://doc.qt.io/qt-6/qttypes.html#qreal-typedef)))[](https://code.qt.io/cgit/qt/qtbase.git/tree/src/corelib/animation/qvariantanimation.h?h=6.12#n82 "View declaration of this function")[](https://doc.qt.io/qt-6/qvariantanimation.html#qRegisterAnimationInterpolator "Direct link to this headline")

Registers a custom interpolator _func_ for the template type `T`. The interpolator has to be registered before the animation is constructed. To unregister (and use the default interpolator) set _func_ to `nullptr`.

**Warning:**Registering a custom interpolator for one of the Qt built-in types (e.g. `int`) will affect all animations on this type that will be created later. This might be an undesired behavior. It is therefore recommended to reset the interpolator to the default value after the desired animations have been created.

**Note:** This function is [thread-safe](https://doc.qt.io/qt-6/threads-reentrancy.html).
