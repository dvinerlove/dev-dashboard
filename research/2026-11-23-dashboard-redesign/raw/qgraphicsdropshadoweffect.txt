## Detailed Description[](https://doc.qt.io/qt-6/qgraphicsdropshadoweffect.html#details "Direct link to this headline")

A drop shadow effect renders the source with a drop shadow. The color of the drop shadow can be modified using the [setColor](https://doc.qt.io/qt-6/qgraphicsdropshadoweffect.html#color-prop)() function. The drop shadow offset can be modified using the [setOffset](https://doc.qt.io/qt-6/qgraphicsdropshadoweffect.html#offset-prop)() function and the blur radius of the drop shadow can be changed with the [setBlurRadius](https://doc.qt.io/qt-6/qgraphicsdropshadoweffect.html#blurRadius-prop)() function.

By default, the drop shadow is a semi-transparent dark gray ([QColor](https://doc.qt.io/qt-6/qcolor.html)(63, 63, 63, 180)) shadow, blurred with a radius of 1 at an offset of 8 pixels towards the lower right. The drop shadow offset is specified in device coordinates.

![Image 1: Drop shadow effect on an image of a fish](https://doc.qt.io/qt-6/images/graphicseffect-drop-shadow.png)

**See also**[QGraphicsBlurEffect](https://doc.qt.io/qt-6/qgraphicsblureffect.html), [QGraphicsColorizeEffect](https://doc.qt.io/qt-6/qgraphicscolorizeeffect.html), and [QGraphicsOpacityEffect](https://doc.qt.io/qt-6/qgraphicsopacityeffect.html).

## Property Documentation

### blurRadius : [qreal](https://doc.qt.io/qt-6/qttypes.html#qreal-typedef)[](https://code.qt.io/cgit/qt/qtbase.git/tree/src/widgets/effects/qgraphicseffect.h?h=6.12#n167 "View declaration of this property")[](https://doc.qt.io/qt-6/qgraphicsdropshadoweffect.html#blurRadius-prop "Direct link to this headline")

This property holds the blur radius in pixels of the drop shadow.

Using a smaller radius results in a sharper shadow, whereas using a bigger radius results in a more blurred shadow.

By default, the blur radius is 1 pixel.
