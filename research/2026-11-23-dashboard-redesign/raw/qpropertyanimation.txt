## Detailed Description[](https://doc.qt.io/qt-6/qpropertyanimation.html#details "Direct link to this headline")

QPropertyAnimation interpolates over [Qt properties](https://doc.qt.io/qt-6/properties.html). As property values are stored in [QVariant](https://doc.qt.io/qt-6/qvariant.html)s, the class inherits [QVariantAnimation](https://doc.qt.io/qt-6/qvariantanimation.html), and supports animation of the same [meta types](https://doc.qt.io/qt-6/qmetatype.html#Type-enum) as its super class.

A class declaring properties must be a [QObject](https://doc.qt.io/qt-6/qobject.html). To make it possible to animate a property, it must provide a setter (so that QPropertyAnimation can set the property's value). Note that this makes it possible to animate many of Qt's widgets. Let's look at an example:

```
#include <QApplication>
#include <QPushButton>
#include <QPropertyAnimation>

class MyButtonWidget : public QWidget
{
public:
    MyButtonWidget(QWidget *parent = nullptr);
};

MyButtonWidget::MyButtonWidget(QWidget *parent) : QWidget(parent)
{
    QPushButton *button = new QPushButton(tr("Animated Button"), this);
    QPropertyAnimation *anim = new QPropertyAnimation(button, "pos", this);
    anim->setDuration(10000);
    anim->setStartValue(QPoint(0, 0));
    anim->setEndValue(QPoint(100, 250));
    anim->start();
}

int main(int argc, char *argv[])
{
    QApplication a(argc, argv);
    MyButtonWidget buttonAnimWidget;
    buttonAnimWidget.resize(QSize(800, 600));
    buttonAnimWidget.show();
    return a.exec();
}
```

**Note:**You can also control an animation's lifespan by choosing a [delete policy](https://doc.qt.io/qt-6/qabstractanimation.html#DeletionPolicy-enum) while starting the animation.

The property name and the [QObject](https://doc.qt.io/qt-6/qobject.html) instance of which property should be animated are passed to the constructor. You can then specify the start and end value of the property. The procedure is equal for properties in classes you have implemented yourself–just check with [QVariantAnimation](https://doc.qt.io/qt-6/qvariantanimation.html) that your [QVariant](https://doc.qt.io/qt-6/qvariant.html) type is supported.

The [QVariantAnimation](https://doc.qt.io/qt-6/qvariantanimation.html) class description explains how to set up the animation in detail. Note, however, that if a start value is not set, the property will start at the value it had when the QPropertyAnimation instance was created.

QPropertyAnimation works like a charm on its own. For complex animations that, for instance, contain several objects, [QAnimationGroup](https://doc.qt.io/qt-6/qanimationgroup.html) is provided. An animation group is an animation that can contain other animations, and that can manage when its animations are played. Look at [QParallelAnimationGroup](https://doc.qt.io/qt-6/qparallelanimationgroup.html) for an example.

**See also**[QVariantAnimation](https://doc.qt.io/qt-6/qvariantanimation.html), [QAnimationGroup](https://doc.qt.io/qt-6/qanimationgroup.html), and [The Animation Framework](https://doc.qt.io/qt-6/animation-overview.html).

Reimplements: [QVariantAnimation::updateCurrentValue](https://doc.qt.io/qt-6/qvariantanimation.html#updateCurrentValue)(const QVariant &value).

This virtual function is called by [QVariantAnimation](https://doc.qt.io/qt-6/qvariantanimation.html) whenever the current value changes. _value_ is the new, updated value. It updates the current value of the property on the target object, unless the animation is stopped.
