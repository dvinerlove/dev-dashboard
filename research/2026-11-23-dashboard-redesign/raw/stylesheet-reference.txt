Title: Qt Style Sheets Reference | Qt Widgets

URL Source: https://doc.qt.io/qt-6/stylesheet-reference.html

Published Time: Wed, 30 Sep 2026 06:37:39 GMT

Markdown Content:
Qt Style Sheets support various properties, pseudo-states, and subcontrols that make it possible to customize the look of widgets.

The following table lists the Qt widgets that can be customized using style sheets:

| Widget | How to Style |
| --- | --- |
| [QAbstractScrollArea](https://doc.qt.io/qt-6/qabstractscrollarea.html) | Supports the [box model](https://doc.qt.io/qt-6/stylesheet-customizing.html#the-box-model). All derivatives of [QAbstractScrollArea](https://doc.qt.io/qt-6/qabstractscrollarea.html), including [QTextEdit](https://doc.qt.io/qt-6/qtextedit.html), and [QAbstractItemView](https://doc.qt.io/qt-6/qabstractitemview.html) (all item view classes), support scrollable backgrounds using [background-attachment](https://doc.qt.io/qt-6/stylesheet-reference.html#background-attachment-prop). Setting the background-attachment to `fixed` provides a background-image that does not scroll with the viewport. Setting the background-attachment to `scroll`, scrolls the background-image when the scroll bars move. See [Customizing QAbstractScrollArea](https://doc.qt.io/qt-6/stylesheet-examples.html#customizing-qabstractscrollarea) for an example. |
| [QCheckBox](https://doc.qt.io/qt-6/qcheckbox.html) | Supports the [box model](https://doc.qt.io/qt-6/stylesheet-customizing.html#the-box-model). The check indicator can be styled using the [::indicator](https://doc.qt.io/qt-6/stylesheet-reference.html#indicator-sub) subcontrol. By default, the indicator is placed in the Top Left corner of the Contents rectangle of the widget. The [spacing](https://doc.qt.io/qt-6/stylesheet-reference.html#spacing-prop) property specifies the spacing between the check indicator and the text. See [Customizing QCheckBox](https://doc.qt.io/qt-6/stylesheet-examples.html#customizing-qcheckbox) for an example. |
| [QColumnView](https://doc.qt.io/qt-6/qcolumnview.html) | The grip can be styled by using the [image](https://doc.qt.io/qt-6/stylesheet-reference.html#image-prop) property. The arrow indicators can by styled using the [::left-arrow](https://doc.qt.io/qt-6/stylesheet-reference.html#left-arrow-sub) subcontrol and the [::right-arrow](https://doc.qt.io/qt-6/stylesheet-reference.html#right-arrow-sub) subcontrol. |
| [QComboBox](https://doc.qt.io/qt-6/qcombobox.html) | The frame around the combobox can be styled using the [box model](https://doc.qt.io/qt-6/stylesheet-customizing.html#the-box-model). The drop-down button can be styled using the [::drop-down](https://doc.qt.io/qt-6/stylesheet-reference.html#drop-down-sub) subcontrol. By default, the drop-down button is placed in the top right corner of the padding rectangle of the widget. The arrow mark inside the drop-down button can be styled using the [::down-arrow](https://doc.qt.io/qt-6/stylesheet-reference.html#down-arrow-sub) subcontrol. By default, the arrow is placed in the center of the contents rectangle of the drop-down subcontrol. The color of the placeholder text can be set using the [placeholder-text-color](https://doc.qt.io/qt-6/stylesheet-reference.html#placeholder-text-color-prop) property. See [Customizing QComboBox](https://doc.qt.io/qt-6/stylesheet-examples.html#customizing-qcombobox) for an example. |
| [QDateEdit](https://doc.qt.io/qt-6/qdateedit.html) | See [QSpinBox](https://doc.qt.io/qt-6/stylesheet-reference.html#qspinbox-widget). |
| [QDateTimeEdit](https://doc.qt.io/qt-6/qdatetimeedit.html) | See [QSpinBox](https://doc.qt.io/qt-6/stylesheet-reference.html#qspinbox-widget). |
| [QDialog](https://doc.qt.io/qt-6/qdialog.html) | Supports only the [background](https://doc.qt.io/qt-6/stylesheet-reference.html#background-prop), [background-clip](https://doc.qt.io/qt-6/stylesheet-reference.html#background-clip-prop) and [background-origin](https://doc.qt.io/qt-6/stylesheet-reference.html#background-origin-prop) properties. **Warning:**Make sure you define the [Q_OBJECT](https://doc.qt.io/qt-6/qobject.html#Q_OBJECT) macro for your custom widget. |
| [QDialogButtonBox](https://doc.qt.io/qt-6/qdialogbuttonbox.html) | The layout of buttons can be altered using the [button-layout](https://doc.qt.io/qt-6/stylesheet-reference.html#button-layout-prop) property. |
| [QDockWidget](https://doc.qt.io/qt-6/qdockwidget.html) | Supports styling of the title bar and the title bar buttons when docked. The dock widget border can be styled using the [border](https://doc.qt.io/qt-6/stylesheet-reference.html#border-prop) property. The [::title](https://doc.qt.io/qt-6/stylesheet-reference.html#title-sub) subcontrol can be used to customize the title bar. The close and float buttons are positioned with respect to the [::title](https://doc.qt.io/qt-6/stylesheet-reference.html#title-sub) subcontrol using the [::close-button](https://doc.qt.io/qt-6/stylesheet-reference.html#close-button-sub) and [::float-button](https://doc.qt.io/qt-6/stylesheet-reference.html#float-button-sub) respectively. When the title bar is vertical, the [:vertical](https://doc.qt.io/qt-6/stylesheet-reference.html#vertical-ps) pseudo class is set. In addition, depending on [QDockWidget::DockWidgetFeature](https://doc.qt.io/qt-6/qdockwidget.html#DockWidgetFeature-enum), the [:closable](https://doc.qt.io/qt-6/stylesheet-reference.html#closable-ps), [:floatable](https://doc.qt.io/qt-6/stylesheet-reference.html#floatable-ps) and [:movable](https://doc.qt.io/qt-6/stylesheet-reference.html#movable-ps) pseudo states are set. **Note:**Use QMainWindow::separator to style the resize handle. **Warning:**The style sheet has no effect when the [QDockWidget](https://doc.qt.io/qt-6/qdockwidget.html) is undocked as Qt uses native top level windows when undocked. See [Customizing QDockWidget](https://doc.qt.io/qt-6/stylesheet-examples.html#customizing-qdockwidget) for an example. |
| [QDoubleSpinBox](https://doc.qt.io/qt-6/qdoublespinbox.html) | See [QSpinBox](https://doc.qt.io/qt-6/stylesheet-reference.html#qspinbox-widget). |
| [QFrame](https://doc.qt.io/qt-6/qframe.html) | Supports the [box model](https://doc.qt.io/qt-6/stylesheet-customizing.html#the-box-model). Since 4.3, setting a stylesheet on a [QLabel](https://doc.qt.io/qt-6/qlabel.html) automatically sets the [QFrame::frameStyle](https://doc.qt.io/qt-6/qframe.html#frameStyle) property to [QFrame::StyledPanel](https://doc.qt.io/qt-6/qframe.html#Shape-enum). See [Customizing QFrame](https://doc.qt.io/qt-6/stylesheet-examples.html#customizing-qframe) for an example. |
| [QGroupBox](https://doc.qt.io/qt-6/qgroupbox.html) | Supports the [box model](https://doc.qt.io/qt-6/stylesheet-customizing.html#the-box-model). The title can be styled using the [::title](https://doc.qt.io/qt-6/stylesheet-reference.html#title-sub) subcontrol. By default, the title is placed depending on QGroupBox::textAlignment. In the case of a checkable [QGroupBox](https://doc.qt.io/qt-6/qgroupbox.html), the title includes the check indicator. The indicator is styled using the [::indicator](https://doc.qt.io/qt-6/stylesheet-reference.html#indicator-sub) subcontrol. The [spacing](https://doc.qt.io/qt-6/stylesheet-reference.html#spacing-prop) property can be used to control the spacing between the text and indicator. See [Customizing QGroupBox](https://doc.qt.io/qt-6/stylesheet-examples.html#customizing-qgroupbox) for an example. |
| [QHeaderView](https://doc.qt.io/qt-6/qheaderview.html) | Supports the [box model](https://doc.qt.io/qt-6/stylesheet-customizing.html#the-box-model). The sections of the header view are styled using the [::section](https://doc.qt.io/qt-6/stylesheet-reference.html#section-sub) sub control. The `section` Sub-control supports the [:middle](https://doc.qt.io/qt-6/stylesheet-reference.html#middle-ps), [:first](https://doc.qt.io/qt-6/stylesheet-reference.html#first-ps), [:last](https://doc.qt.io/qt-6/stylesheet-reference.html#last-ps), [:only-one](https://doc.qt.io/qt-6/stylesheet-reference.html#only-one-ps), [:next-selected](https://doc.qt.io/qt-6/stylesheet-reference.html#next-selected-ps), [:previous-selected](https://doc.qt.io/qt-6/stylesheet-reference.html#previous-selected-ps), [:selected](https://doc.qt.io/qt-6/stylesheet-reference.html#selected-ps), and [:checked](https://doc.qt.io/qt-6/stylesheet-reference.html#checked-ps) pseudo states. The sort indicator can be styled using the [::up-arrow](https://doc.qt.io/qt-6/stylesheet-reference.html#up-arrow-sub) and the [::down-arrow](https://doc.qt.io/qt-6/stylesheet-reference.html#down-arrow-sub) Sub-control. See [Customizing QHeaderView](https://doc.qt.io/qt-6/stylesheet-examples.html#customizing-qheaderview) for an example. |
| [QLabel](https://doc.qt.io/qt-6/qlabel.html) | Supports the [box model](https://doc.qt.io/qt-6/stylesheet-customizing.html#the-box-model). Does not support the [:hover](https://doc.qt.io/qt-6/stylesheet-reference.html#hover-ps) pseudo-state. Since 4.3, setting a stylesheet on a [QLabel](https://doc.qt.io/qt-6/qlabel.html) automatically sets the [QFrame::frameStyle](https://doc.qt.io/qt-6/qframe.html#frameStyle) property to [QFrame::StyledPanel](https://doc.qt.io/qt-6/qframe.html#Shape-enum). See [Customizing QFrame](https://doc.qt.io/qt-6/stylesheet-examples.html#customizing-qframe) for an example (a [QLabel](https://doc.qt.io/qt-6/qlabel.html) derives from [QFrame](https://doc.qt.io/qt-6/qframe.html)). |
| [QLineEdit](https://doc.qt.io/qt-6/qlineedit.html) | Supports the [box model](https://doc.qt.io/qt-6/stylesheet-customizing.html#the-box-model). The color and background of the selected item is styled using [selection-color](https://doc.qt.io/qt-6/stylesheet-reference.html#selection-color-prop) and [selection-background-color](https://doc.qt.io/qt-6/stylesheet-reference.html#selection-background-color-prop) respectively. The color of the placeholder text can be set using the [placeholder-text-color](https://doc.qt.io/qt-6/stylesheet-reference.html#placeholder-text-color-prop) property. The password character can be styled using the [lineedit-password-character](https://doc.qt.io/qt-6/stylesheet-reference.html#lineedit-password-character-prop) property. The password mask delay can be changed using the [lineedit-password-mask-delay](https://doc.qt.io/qt-6/stylesheet-reference.html#lineedit-password-mask-delay-prop) See [Customizing QLineEdit](https://doc.qt.io/qt-6/stylesheet-examples.html#customizing-qlineedit) for an example. |
| [QListView](https://doc.qt.io/qt-6/qlistview.html) | Supports the [box model](https://doc.qt.io/qt-6/stylesheet-customizing.html#the-box-model). When [alternating row colors](https://doc.qt.io/qt-6/qabstractitemview.html#alternatingRowColors-prop) is enabled, the alternating colors can be styled using the [alternate-background-color](https://doc.qt.io/qt-6/stylesheet-reference.html#alternate-background-color-prop) property. The color and background of the selected item is styled using [selection-color](https://doc.qt.io/qt-6/stylesheet-reference.html#selection-color-prop) and [selection-background-color](https://doc.qt.io/qt-6/stylesheet-reference.html#selection-background-color-prop) respectively. The selection behavior is controlled by the [show-decoration-selected](https://doc.qt.io/qt-6/stylesheet-reference.html#show-decoration-selected-prop) property. Use the [::item](https://doc.qt.io/qt-6/stylesheet-reference.html#item-sub) subcontrol for more fine grained control over the items in the [QListView](https://doc.qt.io/qt-6/qlistview.html). See [QAbstractScrollArea](https://doc.qt.io/qt-6/stylesheet-reference.html#qabstractscrollarea-widget) to style scrollable backgrounds. See [Customzing QListView](https://doc.qt.io/qt-6/stylesheet-examples.html#customizing-qlistview) for an example. |
| [QListWidget](https://doc.qt.io/qt-6/qlistwidget.html) | See [QListView](https://doc.qt.io/qt-6/stylesheet-reference.html#qlistview-widget). |
| [QMainWindow](https://doc.qt.io/qt-6/qmainwindow.html) | Supports styling of the separator. The separator in a [QMainWindow](https://doc.qt.io/qt-6/qmainwindow.html) when using [QDockWidget](https://doc.qt.io/qt-6/qdockwidget.html) is styled using the [::separator](https://doc.qt.io/qt-6/stylesheet-reference.html#separator-sub) subcontrol. See [Customizing QMainWindow](https://doc.qt.io/qt-6/stylesheet-examples.html#customizing-qmainwindow) for an example. |
| [QMenu](https://doc.qt.io/qt-6/qmenu.html) | Supports the [box model](https://doc.qt.io/qt-6/stylesheet-customizing.html#the-box-model). Individual items are styled using the [::item](https://doc.qt.io/qt-6/stylesheet-reference.html#item-sub) subcontrol. In addition to the usually supported pseudo states, `item` subcontrol supports the [:selected](https://doc.qt.io/qt-6/stylesheet-reference.html#selected-ps), [:default](https://doc.qt.io/qt-6/stylesheet-reference.html#default-ps), [:exclusive](https://doc.qt.io/qt-6/stylesheet-reference.html#exclusive-ps) and the [non-exclusive](https://doc.qt.io/qt-6/stylesheet-reference.html#non-exclusive-ps) pseudo states. The indicator of checkable menu items is styled using the [::indicator](https://doc.qt.io/qt-6/stylesheet-reference.html#indicator-sub) subcontrol. The separator is styled using the [::separator](https://doc.qt.io/qt-6/stylesheet-reference.html#separator-sub) subcontrol. For items with a sub menu, the arrow marks are styled using the [right-arrow](https://doc.qt.io/qt-6/stylesheet-reference.html#right-arrow-sub) and [left-arrow](https://doc.qt.io/qt-6/stylesheet-reference.html#left-arrow-sub). The scroller is styled using the [::scroller](https://doc.qt.io/qt-6/stylesheet-reference.html#scroller-sub). The tear-off is styled using the [::tearoff](https://doc.qt.io/qt-6/stylesheet-reference.html#tearoff-sub). See [Customizing QMenu](https://doc.qt.io/qt-6/stylesheet-examples.html#customizing-qmenu) for an example. |
| [QMenuBar](https://doc.qt.io/qt-6/qmenubar.html) | Supports the [box model](https://doc.qt.io/qt-6/stylesheet-customizing.html#the-box-model). The [spacing](https://doc.qt.io/qt-6/stylesheet-reference.html#spacing-prop) property specifies the spacing between menu items. Individual items are styled using the [::item](https://doc.qt.io/qt-6/stylesheet-reference.html#item-sub) subcontrol. **Warning:**When running on Qt/Mac, the menu bar is usually embedded into the system-wide menu bar. In this case, the style sheet will have no effect. See [Customizing QMenuBar](https://doc.qt.io/qt-6/stylesheet-examples.html#customizing-qmenubar) for an example. |
| [QMessageBox](https://doc.qt.io/qt-6/qmessagebox.html) | The [messagebox-text-interaction-flags](https://doc.qt.io/qt-6/stylesheet-reference.html#messagebox-text-interaction-flags-prop) property can be used to alter the interaction with text in the message box. |
| [QProgressBar](https://doc.qt.io/qt-6/qprogressbar.html) | Supports the [box model](https://doc.qt.io/qt-6/stylesheet-customizing.html#the-box-model). The chunks of the progress bar can be styled using the [::chunk](https://doc.qt.io/qt-6/stylesheet-reference.html#chunk-sub) subcontrol. The chunk is displayed on the Contents rectangle of the widget. If the progress bar displays text, use the [text-align](https://doc.qt.io/qt-6/stylesheet-reference.html#text-align-prop) property to position the text. Indeterminate progress bars have the [:indeterminate](https://doc.qt.io/qt-6/stylesheet-reference.html#indeterminate-ps) pseudo state set. See [Customizing QProgressBar](https://doc.qt.io/qt-6/stylesheet-examples.html#customizing-qprogressbar) for an example. |
| [QPushButton](https://doc.qt.io/qt-6/qpushbutton.html) | Supports the [box model](https://doc.qt.io/qt-6/stylesheet-customizing.html#the-box-model). Supports the [:default](https://doc.qt.io/qt-6/stylesheet-reference.html#default-ps), [:flat](https://doc.qt.io/qt-6/stylesheet-reference.html#flat-ps), [:checked](https://doc.qt.io/qt-6/stylesheet-reference.html#checked-ps) pseudo states. Since 5.15, the [icon](https://doc.qt.io/qt-6/stylesheet-reference.html#icon-prop) property can be set to override the button icon. For [QPushButton](https://doc.qt.io/qt-6/qpushbutton.html) with a menu, the menu indicator is styled using the [::menu-indicator](https://doc.qt.io/qt-6/stylesheet-reference.html#menu-indicator-sub) subcontrol. Appearance of checkable push buttons can be customized using the [:open](https://doc.qt.io/qt-6/stylesheet-reference.html#open-ps) and [:closed](https://doc.qt.io/qt-6/stylesheet-reference.html#closed-ps) pseudo-states. **Warning:**If you only set a background-color on a [QPushButton](https://doc.qt.io/qt-6/qpushbutton.html), the background may not appear unless you set the border property to some value. This is because, by default, the [QPushButton](https://doc.qt.io/qt-6/qpushbutton.html) draws a native border which completely overlaps the background-color. For example, `QPushButton { background-color: red; border: none; }` See [Customizing QPushButton](https://doc.qt.io/qt-6/stylesheet-examples.html#customizing-qpushbutton) for an example. |
| [QRadioButton](https://doc.qt.io/qt-6/qradiobutton.html) | Supports the [box model](https://doc.qt.io/qt-6/stylesheet-customizing.html#the-box-model). The check indicator can be styled using the [::indicator](https://doc.qt.io/qt-6/stylesheet-reference.html#indicator-sub) subcontrol. By default, the indicator is placed in the Top Left corner of the Contents rectangle of the widget. The [spacing](https://doc.qt.io/qt-6/stylesheet-reference.html#spacing-prop) property specifies the spacing between the check indicator and the text. See [Customizing QRadioButton](https://doc.qt.io/qt-6/stylesheet-examples.html#customizing-qradiobutton) for an example. |
| [QScrollBar](https://doc.qt.io/qt-6/qscrollbar.html) | Supports the [box model](https://doc.qt.io/qt-6/stylesheet-customizing.html#the-box-model). The Contents rectangle of the widget is considered to be the groove over which the slider moves. The extent of the [QScrollBar](https://doc.qt.io/qt-6/qscrollbar.html) (i.e the width or the height depending on the orientation) is set using the [width](https://doc.qt.io/qt-6/stylesheet-reference.html#width-prop) or [height](https://doc.qt.io/qt-6/stylesheet-reference.html#height-prop) property respectively. To determine the orientation, use the [:horizontal](https://doc.qt.io/qt-6/stylesheet-reference.html#horizontal-ps) and the [:vertical](https://doc.qt.io/qt-6/stylesheet-reference.html#vertical-ps) pseudo states. The slider can be styled using the [::handle](https://doc.qt.io/qt-6/stylesheet-reference.html#handle-sub) subcontrol. Setting the [min-width](https://doc.qt.io/qt-6/stylesheet-reference.html#min-width-prop) or [min-height](https://doc.qt.io/qt-6/stylesheet-reference.html#min-height-prop) provides size constraints for the slider depending on the orientation. The [::add-line](https://doc.qt.io/qt-6/stylesheet-reference.html#add-line-sub) subcontrol can be used to style the button to add a line. By default, the add-line subcontrol is placed in top right corner of the Border rectangle of the widget. Depending on the orientation the [::right-arrow](https://doc.qt.io/qt-6/stylesheet-reference.html#right-arrow-sub) or [::down-arrow](https://doc.qt.io/qt-6/stylesheet-reference.html#down-arrow-sub). By default, the arrows are placed in the center of the Contents rectangle of the add-line subcontrol. The [::sub-line](https://doc.qt.io/qt-6/stylesheet-reference.html#sub-line-sub) subcontrol can be used to style the button to subtract a line. By default, the sub-line subcontrol is placed in bottom right corner of the Border rectangle of the widget. Depending on the orientation the [::left-arrow](https://doc.qt.io/qt-6/stylesheet-reference.html#left-arrow-sub) or [::up-arrow](https://doc.qt.io/qt-6/stylesheet-reference.html#up-arrow-sub). By default, the arrows are placed in the center of the Contents rectangle of the sub-line subcontrol. The [::sub-page](https://doc.qt.io/qt-6/stylesheet-reference.html#sub-page-sub) subcontrol can be used to style the region of the slider that subtracts a page. The [::add-page](https://doc.qt.io/qt-6/stylesheet-reference.html#add-page-sub) subcontrol can be used to style the region of the slider that adds a page. See [Customizing QScrollBar](https://doc.qt.io/qt-6/stylesheet-examples.html#customizing-qscrollbar) for an example. |
| [QSizeGrip](https://doc.qt.io/qt-6/qsizegrip.html) | Supports the [width](https://doc.qt.io/qt-6/stylesheet-reference.html#width-prop), [height](https://doc.qt.io/qt-6/stylesheet-reference.html#height-prop), and [image](https://doc.qt.io/qt-6/stylesheet-reference.html#image-prop) properties. See [Customizing QSizeGrip](https://doc.qt.io/qt-6/stylesheet-examples.html#customizing-qsizegrip) for an example. |
| [QSlider](https://doc.qt.io/qt-6/qslider.html) | Supports the [box model](https://doc.qt.io/qt-6/stylesheet-customizing.html#the-box-model). For horizontal slides, the [min-width](https://doc.qt.io/qt-6/stylesheet-reference.html#min-width-prop) and [height](https://doc.qt.io/qt-6/stylesheet-reference.html#height-prop) properties must be provided. For vertical sliders, the [min-height](https://doc.qt.io/qt-6/stylesheet-reference.html#min-height-prop) and [width](https://doc.qt.io/qt-6/stylesheet-reference.html#width-prop) properties must be provided. The groove of the slider is styled using the [::groove](https://doc.qt.io/qt-6/stylesheet-reference.html#groove-sub). The groove is positioned by default in the Contents rectangle of the widget. The thumb of the slider is styled using [::handle](https://doc.qt.io/qt-6/stylesheet-reference.html#handle-sub) subcontrol. The subcontrol moves in the Contents rectangle of the groove subcontrol. See [Customizing QSlider](https://doc.qt.io/qt-6/stylesheet-examples.html#customizing-qslider) for an example. |
| [QSpinBox](https://doc.qt.io/qt-6/qspinbox.html) | The frame of the spin box can be styled using the [box model](https://doc.qt.io/qt-6/stylesheet-customizing.html#the-box-model). The up button and arrow can be styled using the [::up-button](https://doc.qt.io/qt-6/stylesheet-reference.html#up-button-sub) and [::up-arrow](https://doc.qt.io/qt-6/stylesheet-reference.html#up-arrow-sub) subcontrols. By default, the up-button is placed in the top right corner in the Padding rectangle of the widget. Without an explicit size, it occupies half the height of its reference rectangle. The up-arrow is placed in the center of the Contents rectangle of the up-button. The down button and arrow can be styled using the [::down-button](https://doc.qt.io/qt-6/stylesheet-reference.html#down-button-sub) and [::down-arrow](https://doc.qt.io/qt-6/stylesheet-reference.html#down-arrow-sub) subcontrols. By default, the down-button is placed in the bottom right corner in the Padding rectangle of the widget. Without an explicit size, it occupies half the height of its reference rectangle. The bottom-arrow is placed in the center of the Contents rectangle of the bottom-button. See [Customizing QSpinBox](https://doc.qt.io/qt-6/stylesheet-examples.html#customizing-qspinbox) for an example. |
| [QSplitter](https://doc.qt.io/qt-6/qsplitter.html) | Supports the [box model](https://doc.qt.io/qt-6/stylesheet-customizing.html#the-box-model). The handle of the splitter is styled using the [::handle](https://doc.qt.io/qt-6/stylesheet-reference.html#handle-sub) subcontrol. See [Customizing QSplitter](https://doc.qt.io/qt-6/stylesheet-examples.html#customizing-qsplitter) for an example. |
| [QStatusBar](https://doc.qt.io/qt-6/qstatusbar.html) | Supports only the [background](https://doc.qt.io/qt-6/stylesheet-reference.html#background-prop) property. The frame for individual items can be style using the [::item](https://doc.qt.io/qt-6/stylesheet-reference.html#item-sub) subcontrol. See [Customizing QStatusBar](https://doc.qt.io/qt-6/stylesheet-examples.html#customizing-qstatusbar) for an example. |
| [QTabBar](https://doc.qt.io/qt-6/qtabbar.html) | Individual tabs may be styled using the [::tab](https://doc.qt.io/qt-6/stylesheet-reference.html#tab-sub) subcontrol. Close buttons using the [::close-button](https://doc.qt.io/qt-6/stylesheet-reference.html#close-button-sub). *   [messagebox-text-interaction-flags*](https://doc.qt.io/qt-6/stylesheet-reference.html#messagebox-text-interaction-flags)

### accent-color[](https://doc.qt.io/qt-6/stylesheet-reference.html#accent-color "Direct link to this headline")

The property sets the `Accent`, which is used to emphasize interactive UI elements. If this property is not set, it defaults to the `highlight` color.

### alternate-background-color[](https://doc.qt.io/qt-6/stylesheet-reference.html#alternate-background-color "Direct link to this headline")

The [alternate background color](https://doc.qt.io/qt-6/qabstractitemview.html#alternatingRowColors-prop) used in [QAbstractItemView](https://doc.qt.io/qt-6/qabstractitemview.html) subclasses.

If this property is not set, the default value is whatever is set for the palette's [AlternateBase](https://doc.qt.io/qt-6/qpalette.html#ColorRole-enum) role.

Example:

```
QTreeView {
    alternate-background-color: blue;
    background: yellow;
}
```

See also [background](https://doc.qt.io/qt-6/stylesheet-reference.html#background-prop) and [selection-background-color](https://doc.qt.io/qt-6/stylesheet-reference.html#selection-background-color-prop).

### background[](https://doc.qt.io/qt-6/stylesheet-reference.html#background "Direct link to this headline")

Shorthand notation for setting the background. Equivalent to specifying `background-color`, `background-image`, `background-repeat`, and/or `background-position`.

This property is supported by [QAbstractItemView](https://doc.qt.io/qt-6/qabstractitemview.html) subclasses, [QAbstractSpinBox](https://doc.qt.io/qt-6/qabstractspinbox.html) subclasses, [QCheckBox](https://doc.qt.io/qt-6/qcheckbox.html), [QComboBox](https://doc.qt.io/qt-6/qcombobox.html), [QDialog](https://doc.qt.io/qt-6/qdialog.html), [QFrame](https://doc.qt.io/qt-6/qframe.html), [QGroupBox](https://doc.qt.io/qt-6/qgroupbox.html), [QLabel](https://doc.qt.io/qt-6/qlabel.html), [QLineEdit](https://doc.qt.io/qt-6/qlineedit.html), [QMenu](https://doc.qt.io/qt-6/qmenu.html), [QMenuBar](https://doc.qt.io/qt-6/qmenubar.html), [QPushButton](https://doc.qt.io/qt-6/qpushbutton.html), [QRadioButton](https://doc.qt.io/qt-6/qradiobutton.html), [QSplitter](https://doc.qt.io/qt-6/qsplitter.html), [QTextEdit](https://doc.qt.io/qt-6/qtextedit.html), [QToolTip](https://doc.qt.io/qt-6/qtooltip.html), and plain [QWidget](https://doc.qt.io/qt-6/qwidget.html)s.

Example:

Often, it is required to set a fill pattern similar to the styles in [Qt::BrushStyle](https://doc.qt.io/qt-6/qt.html#BrushStyle-enum). You can use the background-color property for [Qt::SolidPattern](https://doc.qt.io/qt-6/qt.html#BrushStyle-enum), [Qt::RadialGradientPattern](https://doc.qt.io/qt-6/qt.html#BrushStyle-enum), [Qt::LinearGradientPattern](https://doc.qt.io/qt-6/qt.html#BrushStyle-enum) and [Qt::ConicalGradientPattern](https://doc.qt.io/qt-6/qt.html#BrushStyle-enum). The other patterns are easily achieved by creating a background image that contains the pattern.

Example:

```
QLabel {
    background-image: url(dense6pattern.png);
    background-repeat: repeat-xy;
}
```

See also [background-origin](https://doc.qt.io/qt-6/stylesheet-reference.html#background-origin-prop), [selection-background-color](https://doc.qt.io/qt-6/stylesheet-reference.html#selection-background-color-prop), [background-clip](https://doc.qt.io/qt-6/stylesheet-reference.html#background-clip-prop), [background-attachment](https://doc.qt.io/qt-6/stylesheet-reference.html#background-attachment-prop) and [alternate-background-color](https://doc.qt.io/qt-6/stylesheet-reference.html#alternate-background-color-prop).

### background-color[](https://doc.qt.io/qt-6/stylesheet-reference.html#background-color "Direct link to this headline")

The background color used for the widget.

Examples:

```
QLabel { background-color: yellow }
QLineEdit { background-color: rgb(255, 0, 0) }
```

### background-image[](https://doc.qt.io/qt-6/stylesheet-reference.html#background-image "Direct link to this headline")

The background image used for the widget. Semi-transparent parts of the image let the `background-color` shine through.

Example:

`QFrame { background-image: url(:/images/hydro.png) }`

### background-repeat[](https://doc.qt.io/qt-6/stylesheet-reference.html#background-repeat "Direct link to this headline")

Whether and how the background image is repeated to fill the `background-origin` rectangle.

If this property is not specified, the background image is repeated in both directions (`repeat`).

Example:

```
QFrame {
    background: white url(:/images/ring.png);
    background-repeat: repeat-y;
    background-position: left;
}
```

### background-position[](https://doc.qt.io/qt-6/stylesheet-reference.html#background-position "Direct link to this headline")

The alignment of the background image within the `background-origin` rectangle.

If this property is not specified, the alignment is `top``left`.

Example:

```
QFrame {
    background: url(:/images/footer.png);
    background-position: bottom left;
}
```

### background-attachment[](https://doc.qt.io/qt-6/stylesheet-reference.html#background-attachment "Direct link to this headline")

Determines whether the background-image in a [QAbstractScrollArea](https://doc.qt.io/qt-6/qabstractscrollarea.html) is scrolled or fixed with respect to the viewport. By default, the background-image scrolls with the viewport.

Example:

```
QTextEdit {
    background-image: url("leaves.png");
    background-attachment: fixed;
}
```

See also [background](https://doc.qt.io/qt-6/stylesheet-reference.html#background-prop)

### background-clip[](https://doc.qt.io/qt-6/stylesheet-reference.html#background-clip "Direct link to this headline")

The widget's rectangle, in which the `background` is drawn.

This property specifies the rectangle to which the `background-color` and `background-image` are clipped.

This property is supported by [QAbstractItemView](https://doc.qt.io/qt-6/qabstractitemview.html) subclasses, [QAbstractSpinBox](https://doc.qt.io/qt-6/qabstractspinbox.html) subclasses, [QCheckBox](https://doc.qt.io/qt-6/qcheckbox.html), [QComboBox](https://doc.qt.io/qt-6/qcombobox.html), [QDialog](https://doc.qt.io/qt-6/qdialog.html), [QFrame](https://doc.qt.io/qt-6/qframe.html), [QGroupBox](https://doc.qt.io/qt-6/qgroupbox.html), [QLabel](https://doc.qt.io/qt-6/qlabel.html), [QPushButton](https://doc.qt.io/qt-6/qpushbutton.html), [QRadioButton](https://doc.qt.io/qt-6/qradiobutton.html), [QSplitter](https://doc.qt.io/qt-6/qsplitter.html), [QTextEdit](https://doc.qt.io/qt-6/qtextedit.html), [QToolTip](https://doc.qt.io/qt-6/qtooltip.html), and plain [QWidget](https://doc.qt.io/qt-6/qwidget.html)s.

If this property is not specified, the default is `border`.

Example:

```
QFrame {
    background-image: url(:/images/header.png);
    background-position: top left;
    background-origin: content;
    background-clip: padding;
}
```

See also [background](https://doc.qt.io/qt-6/stylesheet-reference.html#background-prop), [background-origin](https://doc.qt.io/qt-6/stylesheet-reference.html#background-origin-prop) and [The Box Model](https://doc.qt.io/qt-6/stylesheet-customizing.html#the-box-model).

### background-origin[](https://doc.qt.io/qt-6/stylesheet-reference.html#background-origin "Direct link to this headline")

The widget's background rectangle, to use in conjunction with `background-position` and `background-image`.

This property is supported by [QAbstractItemView](https://doc.qt.io/qt-6/qabstractitemview.html) subclasses, [QAbstractSpinBox](https://doc.qt.io/qt-6/qabstractspinbox.html) subclasses, [QCheckBox](https://doc.qt.io/qt-6/qcheckbox.html), [QComboBox](https://doc.qt.io/qt-6/qcombobox.html), [QDialog](https://doc.qt.io/qt-6/qdialog.html), [QFrame](https://doc.qt.io/qt-6/qframe.html), [QGroupBox](https://doc.qt.io/qt-6/qgroupbox.html), [QLabel](https://doc.qt.io/qt-6/qlabel.html), [QPushButton](https://doc.qt.io/qt-6/qpushbutton.html), [QRadioButton](https://doc.qt.io/qt-6/qradiobutton.html), [QSplitter](https://doc.qt.io/qt-6/qsplitter.html), [QTextEdit](https://doc.qt.io/qt-6/qtextedit.html), [QToolTip](https://doc.qt.io/qt-6/qtooltip.html), and plain [QWidget](https://doc.qt.io/qt-6/qwidget.html)s.

If this property is not specified, the default is `padding`.

Example:

```

    background-image: url(:/images/header.png);
    background-position: top left;
    background-origin: content;
}
```

See also [background](https://doc.qt.io/qt-6/stylesheet-reference.html#background-prop) and [The Box Model](https://doc.qt.io/qt-6/stylesheet-customizing.html#the-box-model).

### image*[](https://doc.qt.io/qt-6/stylesheet-reference.html#image "Direct link to this headline")

The image that is drawn in the contents rectangle of a subcontrol.

The image property accepts a list of [Url](https://doc.qt.io/qt-6/stylesheet-reference.html#url)s or a `svg`. The actual image that is drawn is determined using the same algorithm as [QIcon](https://doc.qt.io/qt-6/qicon.html) (i.e) the image is never scaled up but always scaled down if necessary. If a `svg` is specified, the image is scaled to the size of the contents rectangle. Setting the size of a `svg` can be done with the [width](https://doc.qt.io/qt-6/stylesheet-reference.html#width-prop) and [height](https://doc.qt.io/qt-6/stylesheet-reference.html#height-prop) property (supported since Qt 6.13)

Setting the image property on sub controls implicitly sets the width and height of the sub-control (unless the image in a SVG).

Use [image-position](https://doc.qt.io/qt-6/stylesheet-reference.html#image-position-prop) to align the image within the rectangle.

This property is for subcontrols only–we don't support it for other elements.

**Warning:**The [QIcon](https://doc.qt.io/qt-6/qicon.html) SVG plugin is needed to render SVG images.

Example:

```
// implicitly sets the size of down-button to the
// size of spindown.png
QSpinBox::down-button { image: url(:/images/spindown.png) }
```

Gradients are specified in Object Bounding Mode. Imagine the box in which the gradient is rendered, to have its top left corner at (0, 0) and its bottom right corner at (1, 1). Gradient parameters are then specified as percentages from 0 to 1. These values are extrapolated to actual box coordinates at runtime. Unlike the margins, padding is located inside the border. * `content`: The content rectangle. This specifies where the actual contents go, excluding any padding, border, or margin.
