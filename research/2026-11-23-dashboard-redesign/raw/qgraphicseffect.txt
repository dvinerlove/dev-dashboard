## Detailed Description[](https://doc.qt.io/qt-6/qgraphicseffect.html#details "Direct link to this headline")

Effects alter the appearance of elements by hooking into the rendering pipeline and operating between the source (e.g., a [QGraphicsPixmapItem](https://doc.qt.io/qt-6/qgraphicspixmapitem.html)) and the destination device (e.g., [QGraphicsView](https://doc.qt.io/qt-6/qgraphicsview.html)'s viewport). Effects can be disabled by calling [setEnabled](https://doc.qt.io/qt-6/qgraphicseffect.html#enabled-prop)(false). If effects are disabled, the source is rendered directly.

To add a visual effect to a [QGraphicsItem](https://doc.qt.io/qt-6/qgraphicsitem.html), for example, you can use one of the standard effects, or alternately, create your own effect by creating a subclass of QGraphicsEffect. The effect can then be installed on the item using [QGraphicsItem::setGraphicsEffect](https://doc.qt.io/qt-6/qgraphicsitem.html#setGraphicsEffect)().

Qt provides the following standard effects:

*   [QGraphicsBlurEffect](https://doc.qt.io/qt-6/qgraphicsblureffect.html) - blurs the item by a given radius
*   [QGraphicsDropShadowEffect](https://doc.qt.io/qt-6/qgraphicsdropshadoweffect.html) - renders a dropshadow behind the item
*   [QGraphicsColorizeEffect](https://doc.qt.io/qt-6/qgraphicscolorizeeffect.html) - renders the item in shades of any given color
*   [QGraphicsOpacityEffect](https://doc.qt.io/qt-6/qgraphicsopacityeffect.html) - renders the item with an opacity

For more information on how to use each effect, refer to the specific effect's documentation.

To create your own custom effect, create a subclass of QGraphicsEffect (or any other existing effects) and reimplement the virtual function [draw](https://doc.qt.io/qt-6/qgraphicseffect.html#draw)(). This function is called whenever the effect needs to redraw. The [draw](https://doc.qt.io/qt-6/qgraphicseffect.html#draw)() function takes the painter with which to draw as an argument. For more information, refer to the documentation for [draw](https://doc.qt.io/qt-6/qgraphicseffect.html#draw)(). In the [draw](https://doc.qt.io/qt-6/qgraphicseffect.html#draw)() function you can call [sourcePixmap](https://doc.qt.io/qt-6/qgraphicseffect.html#sourcePixmap)() to get a pixmap of the graphics effect source which you can then process.

If your effect changes, use [update](https://doc.qt.io/qt-6/qgraphicseffect.html#update)() to request for a redraw. If your custom effect changes the bounding rectangle of the source, e.g., a radial glow effect may need to apply an extra margin, you can reimplement the virtual [boundingRectFor](https://doc.qt.io/qt-6/qgraphicseffect.html#boundingRectFor)() function, and call [updateBoundingRect](https://doc.qt.io/qt-6/qgraphicseffect.html#updateBoundingRect)() to notify the framework whenever this rectangle changes. The virtual [sourceChanged](https://doc.qt.io/qt-6/qgraphicseffect.html#sourceChanged)() function is called to notify the effects that the source has changed in some way - e.g., if the source is a [QGraphicsRectItem](https://doc.qt.io/qt-6/qgraphicsrectitem.html) and its rectangle parameters have changed.

### `[pure virtual protected]`void QGraphicsEffect::draw([QPainter](https://doc.qt.io/qt-6/qpainter.html) *_painter_)[](https://code.qt.io/cgit/qt/qtbase.git/tree/src/widgets/effects/qgraphicseffect.h?h=6.12#n64 "View declaration of this function")[](https://doc.qt.io/qt-6/qgraphicseffect.html#draw "Direct link to this headline")

This pure virtual function draws the effect and is called whenever the source needs to be drawn.

Reimplement this function in a [QGraphicsEffect](https://doc.qt.io/qt-6/qgraphicseffect.html) subclass to provide the effect's drawing implementation, using _painter_.

For example:

```
void MyGraphicsEffect::draw(QPainter *painter)
{
    //...
    QPoint offset;
    if (sourceIsPixmap()) {
        // No point in drawing in device coordinates (pixmap will be scaled anyways).
        const QPixmap pixmap = sourcePixmap(Qt::LogicalCoordinates, &offset);
        //...
        painter->drawPixmap(offset, pixmap);
    } else {
        // Draw pixmap in device coordinates to avoid pixmap scaling;
        const QPixmap pixmap = sourcePixmap(Qt::DeviceCoordinates, &offset);
        painter->setWorldTransform(QTransform());
        //...
        painter->drawPixmap(offset, pixmap);
    }
    //...
}
```

This function should not be called explicitly by the user, since it is meant for reimplementation purposes only.

### `[protected]`void QGraphicsEffect::drawSource([QPainter](https://doc.qt.io/qt-6/qpainter.html) *_painter_)[](https://code.qt.io/cgit/qt/qtbase.git/tree/src/widgets/effects/qgraphicseffect.h?h=6.12#n70 "View declaration of this function")[](https://doc.qt.io/qt-6/qgraphicseffect.html#drawSource "Direct link to this headline")

Draws the source directly using the given _painter_.

This function should only be called from [QGraphicsEffect::draw](https://doc.qt.io/qt-6/qgraphicseffect.html#draw)().

For example:

```
void MyGraphicsOpacityEffect::draw(QPainter *painter)
{
    // Fully opaque; draw directly without going through a pixmap.
    if (qFuzzyCompare(m_opacity, 1)) {
        drawSource(painter);
        return;
    }
    //...
}
```

**See also**[QGraphicsEffect::draw](https://doc.qt.io/qt-6/qgraphicseffect.html#draw)().

### `[protected]`[QRectF](https://doc.qt.io/qt-6/qrectf.html) QGraphicsEffect::sourceBoundingRect([Qt::CoordinateSystem](https://doc.qt.io/qt-6/qt.html#CoordinateSystem-enum)_system_ = Qt::LogicalCoordinates) const[](https://code.qt.io/cgit/qt/qtbase.git/tree/src/widgets/effects/qgraphicseffect.h?h=6.12#n69 "View declaration of this function")[](https://doc.qt.io/qt-6/qgraphicseffect.html#sourceBoundingRect "Direct link to this headline")

Returns the bounding rectangle of the source mapped to the given _system_.

Calling this function with [Qt::DeviceCoordinates](https://doc.qt.io/qt-6/qt.html#CoordinateSystem-enum) outside of [QGraphicsEffect::draw](https://doc.qt.io/qt-6/qgraphicseffect.html#draw)() will give undefined results, as there is no device context available.

### `[virtual protected]`void QGraphicsEffect::sourceChanged([QGraphicsEffect::ChangeFlags](https://doc.qt.io/qt-6/qgraphicseffect.html#ChangeFlag-enum)_flags_)[](https://code.qt.io/cgit/qt/qtbase.git/tree/src/widgets/effects/qgraphicseffect.h?h=6.12#n65 "View declaration of this function")[](https://doc.qt.io/qt-6/qgraphicseffect.html#sourceChanged "Direct link to this headline")

This virtual function is called by [QGraphicsEffect](https://doc.qt.io/qt-6/qgraphicseffect.html) to notify the effect that the source has changed. If the effect applies any cache, then this cache must be purged in order to reflect the new appearance of the source.

The _flags_ describes what has changed.

### `[protected]`bool QGraphicsEffect::sourceIsPixmap() const[](https://code.qt.io/cgit/qt/qtbase.git/tree/src/widgets/effects/qgraphicseffect.h?h=6.12#n68 "View declaration of this function")[](https://doc.qt.io/qt-6/qgraphicseffect.html#sourceIsPixmap "Direct link to this headline")

Returns `true` if the source effectively is a pixmap, e.g., a [QGraphicsPixmapItem](https://doc.qt.io/qt-6/qgraphicspixmapitem.html).

This function is useful for optimization purposes. For instance, there's no point in drawing the source in device coordinates to avoid pixmap scaling if this function returns `true` - the source pixmap will be scaled anyways.

### `[protected]`[QPixmap](https://doc.qt.io/qt-6/qpixmap.html) QGraphicsEffect::sourcePixmap([Qt::CoordinateSystem](https://doc.qt.io/qt-6/qt.html#CoordinateSystem-enum)_system_ = Qt::LogicalCoordinates, [QPoint](https://doc.qt.io/qt-6/qpoint.html) *_offset_ = nullptr, [QGraphicsEffect::PixmapPadMode](https://doc.qt.io/qt-6/qgraphicseffect.html#PixmapPadMode-enum)_mode_ = PadToEffectiveBoundingRect) const[](https://code.qt.io/cgit/qt/qtbase.git/tree/src/widgets/effects/qgraphicseffect.h?h=6.12#n71 "View declaration of this function")[](https://doc.qt.io/qt-6/qgraphicseffect.html#sourcePixmap "Direct link to this headline")

Returns a pixmap with the source painted into it.

The _system_ specifies which coordinate system to be used for the source. The optional _offset_ parameter returns the offset where the pixmap should be painted at using the current painter. For control on how the pixmap is padded use the _mode_ parameter.

The returned pixmap is clipped to the current painter's device rectangle when _system_ is [Qt::DeviceCoordinates](https://doc.qt.io/qt-6/qt.html#CoordinateSystem-enum).

Calling this function with [Qt::DeviceCoordinates](https://doc.qt.io/qt-6/qt.html#CoordinateSystem-enum) outside of [QGraphicsEffect::draw](https://doc.qt.io/qt-6/qgraphicseffect.html#draw)() will give undefined results, as there is no device context available.

**See also**[draw](https://doc.qt.io/qt-6/qgraphicseffect.html#draw)() and [boundingRect](https://doc.qt.io/qt-6/qgraphicseffect.html#boundingRect)().

### `[slot]`void QGraphicsEffect::update()[](https://code.qt.io/cgit/qt/qtbase.git/tree/src/widgets/effects/qgraphicseffect.h?h=6.12#n57 "View declaration of this slot")[](https://doc.qt.io/qt-6/qgraphicseffect.html#update "Direct link to this headline")

Schedules a redraw of the effect. Call this function whenever the effect needs to be redrawn. This function does not trigger a redraw of the source.

**See also**[updateBoundingRect](https://doc.qt.io/qt-6/qgraphicseffect.html#updateBoundingRect)().

### `[protected]`void QGraphicsEffect::updateBoundingRect()[](https://code.qt.io/cgit/qt/qtbase.git/tree/src/widgets/effects/qgraphicseffect.h?h=6.12#n66 "View declaration of this function")[](https://doc.qt.io/qt-6/qgraphicseffect.html#updateBoundingRect "Direct link to this headline")

This function notifies the effect framework when the effect's bounding rectangle has changed. As a custom effect author, you must call this function whenever you change any parameters that will cause the virtual [boundingRectFor](https://doc.qt.io/qt-6/qgraphicseffect.html#boundingRectFor)() function to return a different value.

This function will call [update](https://doc.qt.io/qt-6/qgraphicseffect.html#update)() if this is necessary.

**See also**[boundingRectFor](https://doc.qt.io/qt-6/qgraphicseffect.html#boundingRectFor)(), [boundingRect](https://doc.qt.io/qt-6/qgraphicseffect.html#boundingRect)(), and [sourceBoundingRect](https://doc.qt.io/qt-6/qgraphicseffect.html#sourceBoundingRect)().
