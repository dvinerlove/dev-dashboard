## Key verbatim quotes

1. "A free, open-source local dev server manager for Windows. Start, stop and monitor your frontend, backend, database and ngrok tunnel with one click, with live logs, health checks and auto-restart."
2. "Add a folder once. RunBay finds the servers and their commands for you." / "Press Run all. Everything starts in the right order and waits until each part is ready." / "See what is going on. Live logs, errors, health, CPU and memory for every service."
3. "**Live logs** | Search, copy, export, and a separate **Errors** tab with a count badge"
4. "**Health and stats** | Responding badge, CPU and memory sparklines, uptime"
5. "**Self-healing** | Auto-restart on crash, one-click fix for 'port already in use'"
6. "**Stay organised** | Favourites, groups, search, import / export of your app list"
7. "**Workspaces** | Save a set of apps as a stack and start or stop all of it with one click"
8. "**Quick launcher** | Global hotkey (Ctrl+Alt+R) to search and run any app from anywhere"
9. "**Port map** | Every port in use on the PC, who owns it, which of your apps it blocks, and a kill button"
10. "**Git and packages** | Branch and status per app, Pull button, Install / Build buttons, warning when `package.json` changed"
11. "**Alerts and history** | Notifications for high CPU / memory or silent services, plus a crash and downtime timeline per app"
12. "**Start order** | Say which service waits for which, drawn as a diagram"
13. "**Smarter logs** | Level filter, highlighted stack traces, clickable file paths that open at the right line, history kept across restarts"
14. "Click **Add from folder** and choose your project folder. Check the detected services, then **Save**. Press **Run all**." — 3-step onboarding.
15. "Windows 10 and 11 today. Contributions for macOS and Linux are welcome." — Windows-only Electron app (Batchfile/CSS/HTML/JS).
